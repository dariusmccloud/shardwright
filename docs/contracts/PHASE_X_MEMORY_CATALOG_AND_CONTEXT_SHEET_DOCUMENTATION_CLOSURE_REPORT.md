## 2. Authority Reconciliation

### Governing contract

`PHASE_X_MEMORY_CATALOG_AND_CONTEXT_SHEET_PARENT_ARCHITECTURE_CONTRACT.md` defines
the four semantic products, their derivation boundaries, the required child
jurisdictions, and the stop boundary.

### Authoritative sources

- Existing evidence, governance, publication, revision, and audit ledgers remain
  authoritative for admitted memory and lifecycle history.
- Catalog records, context sheets, typed links, dossiers, and active-continuity
  assemblies are downstream records or projections with only the authority explicitly
  granted by their governing contracts.
- The frozen operational model supplies derivational human purpose; executable child
  contracts supply machine obligations and proof requirements.

### Projection boundary

- A catalog record registers governed authority; it does not replace its source
  lifecycle ledger.
- A context sheet groups governed records; it does not become event authority.
- A typed membership link records a governed association; similarity may nominate but
  cannot validate it.
- A dossier revision is a reproducible, claim-level interpretation; it cannot silently
  create new governed meaning.
- An active-continuity assembly is a bounded projection; retrieval and salience cannot
  activate evidence or decide conflict precedence.

### Lifecycle owners

Existing governance and publication mechanisms continue to own admission, mutation,
supersession, correction, retirement, replay, and recovery of governed memory.
Each new downstream product owns only its separately contracted lifecycle and must
remain reproducible from authoritative inputs and recorded actions.

### Failure behavior

The stack requires refusal, quarantine, preservation of the last lawful state, or an
explicit non-authoritative pending state when evidence, jurisdiction, identity,
lineage, replay, or benchmark proof is insufficient. It does not permit silent repair
or authority inference.
